# Official SciFlawBench tasks

This folder stores the samples that make up the **official SciFlawBench**. Each benchmark version lives in its own subfolder so that any result can be traced back to the exact task set it was produced with.

## Versions

| Version | Folder | Status                                    |
| ------- | ------ | ----------------------------------------- |
| v0      | `v0/`  | Current — initial version of the task set |

## Assets

`assets/` holds local files that tasks depend on (datasets, PDFs, images, ...). To learn how to reference assets in your tasks, see [`assets/README.md`](assets/README.md).
